# NEXUS IA — Documentação

Bem-vindo à documentação do NEXUS IA. Esta pasta contém guias de instalação, arquitetura, referências de API, procedimentos de desenvolvimento, deploy e operação.

Estrutura principal:
- quickstart.md — começo rápido para rodar localmente.
- setup.md — ambiente de desenvolvimento e dependências.
- architecture.md — visão geral da arquitetura e componentes.
- developer_guide.md — organização do código, convenções e fluxo de trabalho.
- api_reference.md — resumo dos endpoints principais.
- plugins.md — como criar e gerenciar plugins.
- rag.md — detalhes do sistema RAG (ingestão e indexação).
- training.md — pipeline de treinamento e fine-tuning.
- inference.md — endpoints e padrões de inferência.
- monitoring.md — métricas, Prometheus, Grafana e healthchecks.
- security.md — práticas e recomendações de segurança.
- deployment.md — exemplos de deploy (docker, compose, k8s).
- contributing.md — guia rápido para contribuições.
- changelog.md — registro de mudanças.
- glossary.md — termos usados no projeto.

Como usar
- Leia quickstart.md para iniciar rapidamente em desenvolvimento.
- Use setup.md para preparar seu ambiente local.
- Consulte developer_guide.md para adicionar/alterar código.
