# Glossário

- RAG — Retrieval-Augmented Generation: combinação de recuperação de documentos + geração LLM.
- Retriever — Componente que busca documentos relevantes no vector store.
- Vector store — Armazenamento de vetores (ex.: pgvector, FAISS).
- LLM — Large Language Model (modelo de linguagem).
- PEFT / LoRA — técnicas de fine-tuning eficiente.
- SSE — Server-Sent Events (streaming).
- OTel — OpenTelemetry (tracing).
